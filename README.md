# レシピかご

レシピの文章から材料だけを取り出して、買い物リストにまとめるWebアプリ。
同じ材料は分量を合計し、売り場を回る順に並べます。

**→ https://libertedebut.github.io/recipe-kago/**

インストールも登録もいりません。Safariの共有ボタンから「ホーム画面に追加」すると、
アプリのように使えます。

## 通信しません

レシピの内容も買い物リストも、**端末の外には出ません**。
サーバーに送る処理はひとつもなく、保存先はブラウザの中（localStorage）です。

## できること

- レシピの文章を貼り付けると、材料名・分量・売り場を取り出す
- 複数のレシピで使う材料は、**分量を合計する**（大さじ1＋大さじ2＝大さじ3）
- 「½個」「1本(30g)」「大1」「2〜3本」などの表記ゆれを吸収する
- 材料ごとに、どの料理のために買うのかを表示する
- 売り場を回る順（野菜→肉魚→乳製品→調味料→その他）に並べる
- 作成日ごとにリストを保存する

## 写真から取り込む

iPhoneのショートカットを使うと、写真を選んで共有するだけで取り込めます。
読み取りはiPhone内蔵の文字認識で行われるので、こちらも通信しません。

作り方は [shortcut-setup.md](shortcut-setup.md) にあります。

## 分量の計算はAIに任せていない

材料の抜き出しも合算も、すべてコードで確定的に処理しています。
AIに数を数えさせると、間違いに見えない嘘の数字が返るためです。

| 入力 | 出力 |
|---|---|
| `½個` + `1個` + `1/2個` | `2個` |
| `1本(30g)` + `1本(80g)` | `2本(110g)` |
| `大1` + `大2` | `大さじ3` |
| `少々` + `小さじ1` | `小さじ1` |

## 開発

編集するのは `core.js` と `app-template.html` の2つです。
`index.html` は生成物なので直接触らないでください。

```bash
node build.mjs   # 1枚のHTMLにまとめる
node test.mjs    # 中核処理の動作確認
```

| ファイル | 中身 |
|---|---|
| `core.js` | 材料の切り出し・分量の合算・カテゴリ判定。画面に依存しない |
| `app-template.html` | 画面（CSSとDOM操作） |
| `build.mjs` | 上の2つを `index.html` にまとめる |
| `test.mjs` | `core.js` の動作確認 |

`index.html` は外部ファイルを一切読みません。保存すればどこでも動きます。
